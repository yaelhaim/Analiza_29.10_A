# תרגיל 1 - כרטיס ביקור חי

בתרגיל הזה בונים עורך כרטיס ביקור: בצד אחד טופס, ובצד השני כרטיס שמתעדכן בזמן שמקלידים. כל הקוד שתכתבו הוא JavaScript שמחבר בין הטופס לכרטיס, ה-HTML וה-CSS כבר מוכנים.

**מה בונים:** דף עם טופס עריכה וכרטיס תצוגה מקדימה שמשתנה בזמן אמת, כולל מונה תווים, בחירת צבע, מצב כהה וכפתור איפוס.

## איך זה צריך להיראות

🎬 **[צפו בסרטון הדגמה של האתר המוכן](https://cdn.jsdelivr.net/gh/Lior3796/dom-01-business-card@main/demo.mp4)** - כך האתר צריך להתנהג כשמסיימים את כל השלבים.

## איך מתחילים

1. לוחצים למעלה על **Use this template** ← **Create a new repository**, ויוצרים ריפו משלכן.
2. עושים `git clone` לריפו החדש ופותחים אותו ב-VS Code.
3. בטרמינל מריצים פעם אחת: `npm install` (צריך Node בגרסה 20 ומעלה. בודקים עם `node -v`).
4. כותבים את כל הקוד בקובץ `script.js`. את `index.html` ו-`style.css` לא צריך לשנות.
5. כדי לראות את הדף פותחים את `index.html` עם Live Server.

## איך בודקים

```bash
npm test
```

- בהתחלה כל הטסטים אדומים (✘). כל טסט מתחיל במספר השלב שהוא בודק.
- מתחת לכל טסט שנכשל כתוב מה לא עבד.
- כשכל הטסטים ירוקים (✔) מופיעה ההודעה **✅ המשימה אושרה** ואפשר לעבור למשימה הבאה.
- אחרי `git push` הטסטים רצים גם ב-GitHub (לשונית Actions). וי ירוק ליד ה-commit = המשימה אושרה.

> אל תשנו את הקבצים בתיקייה `test/`.

## שלבים

### שלב 1: טקסט חי
כשמקלידים בשדות name, job, email ו-bio, הטקסט מופיע מיד בכרטיס (`card-name`, `card-job`, `card-email`, `card-bio`). רווחים בתחילת הטקסט ובסופו לא נספרים. כשהשדה ריק, חוזר טקסט ברירת המחדל שמופיע ב-HTML.

רמז: אירוע `input` נורה בכל הקלדה. אפשר לחבר מאזין אחד ל-form כולו, כי האירוע עולה אליו מהשדות (bubbling).

### שלב 2: אות באווטר
האווטר מציג את האות הראשונה של השם באות גדולה. כשאין שם, מוצג התו `?`.

### שלב 3: מונה תווים
מתחת ל-bio מופיע כמה תווים נשארו מתוך 80 (האלמנט `bio-left`). כשנשארו 10 תווים או פחות, מוסיפים לאלמנט עם המחלקה `counter` את המחלקה `warning`, וכשיש יותר מ-10 מסירים אותה.

רמז: `classList.toggle` מקבל ערך שני בוליאני.

### שלב 4: צבע
בחירת צבע ב-select משנה את הצבע של מסגרת הכרטיס ואת הרקע של האווטר.

רמז: `el.style.borderColor` ו-`el.style.backgroundColor`. האירוע המתאים הוא `change`.

### שלב 5: מצב כהה
לחיצה על `theme-btn` מוסיפה או מסירה את המחלקה `dark` על ה-body. הטקסט של הכפתור מתחלף בין `Dark mode` ל-`Light mode` לפי המצב.

### שלב 6: איפוס
לחיצה על `reset-btn` מנקה את כל השדות, מחזירה את הצבע לברירת המחדל, ומעדכנת את הכרטיס למצב ההתחלתי, כולל האווטר והמונה (80).

רמז: `form.reset()` מנקה את השדות, אבל לא יורה אירועי `input`. צריך לעדכן את הכרטיס בעצמכן.

## בדיקה עצמית
- הקלדה בכל אחד מארבעת השדות משנה את הכרטיס מיד.
- שם עם רווחים בהתחלה (למשל `" dana"`) מציג אווטר D.
- בהקלדת 70 תווים ב-bio המונה אדום.
- בחירת Red צובעת גם את המסגרת וגם את האווטר.
- איפוס מחזיר הכל, ולא נשארת אות בצבע הישן.
